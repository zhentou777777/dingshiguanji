# 自律定时关机（SelfShutdown）

每天定点**强制关机**的本机小工具：单个 EXE、无脚本依赖、双击即用。
开机自启守护，任务被删会自动恢复；同时保留**明确的取消/卸载通道**。

## 下载

→ [Releases](https://github.com/zhentou777777/dingshiguanji/releases) 下载 `SelfShutdown.exe`（单文件约 10MB，无需安装，拷到任何 Windows 电脑双击即用）。

- 关机只调用 Windows 原生 `shutdown.exe`（完整 ACPI 流程：停服务 → 卸载驱动 → 断电），**不影响底层驱动**，与“开始菜单关机”同路径。
- 三个 Windows 计划任务协同：**关机任务**（SYSTEM 最高权限，普通用户杀不掉）、**提醒任务**（倒计时窗口）、**守护任务**（开机/周期检查，自动恢复被删的任务）。

## 快速开始

1. 双击 `SelfShutdown.exe`，弹出设置窗口。
2. 设置“每天关机时间”（如 `22:30`），可按需调整提醒秒数、关机方式等。
3. 点 **“安装 / 重新安装”**（会弹一次 UAC，选“是”）。
4. 完成。到点前会出现倒计时提醒窗口，到点自动关机。

> 建议先点 **“测试：2 分钟后关机”** 验证链路（可勾选“演练模式”只走流程不真关机），确认无误后再设正式时间。

## 界面选项说明

| 分区 | 选项 | 说明 |
| --- | --- | --- |
| 关机设置 | 每天关机时间 | HH:MM，24 小时制 |
| | 关机方式 | `强制`：`shutdown /s /f /t 0`（仅跳过未响应程序）；`优雅`：`shutdown /s /t 10`（给程序 10 秒自行保存，卡死的由系统超时强杀） |
| 提醒设置 | 提前提醒（秒） | 到点前多少秒弹倒计时窗口 |
| | 提醒文案 | 倒计时窗口显示的文字 |
| 任务可靠性 | 失败重试次数 / 间隔 | 任务失败后自动重试（默认 3 次、每次隔 1 分钟） |
| | 电池模式下也运行 | 取消勾选则“仅交流电时运行” |
| | 到点唤醒睡眠中的电脑 | 防止“定时睡眠”躲关机（默认开） |
| 守护任务 | 检查间隔（分钟） | 周期检查任务是否被删/禁用 |
| | 登录时也检查 | 开机、登录时各检查一次 |
| 按钮 | 安装 / 重新安装 | 幂等创建三个计划任务 |
| | 卸载 | 删除全部计划任务 |
| | 测试：2 分钟后关机 | 一次性测试任务 |
| | 恢复正常关机 | 清除“跳过”状态 |

所有设置保存在 EXE 同目录的 `config.json`，改完点“保存并应用”即时生效。

## 取消功能（逃生通道）

倒计时窗口点 **“取消本次关机”**，三种方式：

- **跳过今天**：今晚不关机，明日照常。
- **跳过 N 天**：N 天内不关机，之后自动恢复。
- **关闭软件**：删除全部计划任务，彻底退出自律（之后想开启，双击 EXE 再点“安装”）。

取消记录写在 `state.json`，操作流水写在 `actions.log`，均可自查。

## 卸载

- 设置窗口点 **“卸载”**；或
- 命令行运行 `SelfShutdown.exe --uninstall`。

卸载只删计划任务，程序目录（含 EXE、config.json）可自行整体删除，无残留。

## 重新构建

```bat
build.bat
```

需要 Python 3.11+（含 tkinter，安装时勾选 tcl/tk）。脚本会自动建虚拟环境、装 PyInstaller 并产出根目录的 `SelfShutdown.exe`。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| （无参数） | 打开设置窗口 |
| `--install` / `--uninstall` | 安装 / 卸载计划任务（自动请求管理员权限） |
| `--test` | 创建 2 分钟后触发的一次性测试任务 |
| `--guardian` | 守护：检查并恢复任务（供计划任务调用） |
| `--enforce` | 到点关机（供计划任务调用，读跳过状态） |
| `--warn` | 弹倒计时提醒窗口（供计划任务调用） |
| `--dry-run` | 演练模式：流程照走，不真正关机 |
| `--status` | 查看任务安装状态 |

## 常见问题

**Q：点“安装”没反应/失败？**
需要管理员权限。程序会自动弹 UAC 提权；若你的 Windows 账户不是管理员，则无法创建 SYSTEM 计划任务，请用管理员账户。

**Q：安全软件（360/电脑管家）报警或拦截？**
本工具为本地打包、源码公开（见本仓库 `src/main.py`），无任何网络行为。请将 `SelfShutdown.exe` 加入信任/白名单后重试。

**Q：到点没关机？**
1. 看设置窗口“当前状态”是否三个任务都已安装·启用；
2. 看 `actions.log` 是否有 `enforce` 记录；
3. 是否在“跳过”期内（窗口会显示“已跳过至 XXXX”）；
4. 笔记本合盖睡眠时默认会唤醒执行（“到点唤醒睡眠中的电脑”默认开启）。

**Q：强制关机丢数据怎么办？**
倒计时提醒就是用来保存工作的；也可把“关机方式”改成“优雅”给程序自行保存的时间。关机本身走完整 Windows 流程，不会损伤硬件和驱动。

**Q：快速启动（Fast Startup）有影响吗？**
没有。关机任务是定时触发，与关机事件无关。

## 目录结构

```
dingshiguanji/
├── SelfShutdown.exe   # 主程序（单文件，双击即用）
├── build.bat          # 一键构建脚本
├── src/main.py        # 全部源码
├── config.json        # 设置（首次运行自动生成）
├── state.json         # 跳过状态（取消时生成）
├── actions.log        # 操作流水（自动生成）
```
